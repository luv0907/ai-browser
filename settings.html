Blocks requests to a built-in list of well-known ad and tracker domains, for this profile. This is a curated list of a few hundred common ones — not a full copy of a list like EasyList — so it catches the big, obvious trackers but will miss smaller ones.

As you browse, the full text of each page is added to your own local search index automatically, so your home page search finds pages from your own history before falling back to the web. Nothing leaves this Mac.

When this is off, new tabs open a fixed address instead — like a classic browser homepage.
